# Project instructions

Проект: AI РОП для Bitrix24 / VibeCode.

Цель:
Создать и поддерживать приложение, которое анализирует сделки, задачи, активности, дисциплину менеджеров и помогает руководителю отдела продаж.

Правила:
- Работать аккуратно.
- Не удалять файлы без явного указания.
- Перед крупными изменениями объяснять план.
- После изменений запускать тесты или хотя бы базовую проверку запуска.
- Секреты не хардкодить.
- Все переменные брать из environment variables.
- Для Bitrix24/VibeCode использовать только безопасные read/write операции согласно задаче.
